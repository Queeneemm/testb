# Telegram birthday reminder bot

Telegram-бот для Excel-таблицы дней рождения и напоминаний за 10 дней и в день рождения.

## Возможности

- inline-кнопки в сообщениях бота для загрузки `.xlsx`, выгрузки файла и просмотра таблицы;
- inline-кнопки в сообщениях бота для добавления и удаления админов без перезапуска бота;
- главное меню показывает все действия, а внутри выбранного сценария остается только кнопка «Назад»;
- доступ только для админов;
- ответ без доступа: `для доступа обратись к @ioibrieb`.

## Быстрый старт

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID, например через [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Создайте `.env` и заполните настройки:

   ```env
   BOT_TOKEN=telegram_bot_token
   ADMIN_IDS=123456789
   ```

5. Запустите бота:

   ```bash
   python bot.py
   ```

## Формат Excel-файла

Файл должен быть `.xlsx` и содержать только два столбца:

| ФИО | Дата |
| --- | --- |
| Иванов Иван | 25.10 |
| Петров Петр | 03.01 |

Заголовки должны быть в первой строке: `ФИО`, `Дата`.
