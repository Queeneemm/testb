# Telegram birthday reminder bot

Простой Telegram-бот для хранения Excel-таблицы дней рождения и отправки напоминаний за 10 дней и в день рождения.

## Возможности

- загрузка `.xlsx` файла с двумя столбцами: `ФИО` и `Дата`;
- дата указывается в формате `день.месяц`, например `25.10`;
- выгрузка актуальной таблицы из бота;
- доступ только для Telegram ID из `ADMIN_IDS`;
- ежедневная проверка и уведомления:
  - за 10 дней: `У Владислава день рождения через 10 дней (16.09).`;
  - в день рождения: `У Владислава сегодня день рождения! (16.09)`;
- защита от повторной отправки одного и того же напоминания в один календарный год.

## Быстрый старт

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID, например через [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Скопируйте настройки и заполните их:

   ```bash
   cp .env.example .env
   ```

5. Запустите бота:

   ```bash
   python bot.py
   ```

## Команды

- `/start` — показать справку;
- `/upload` — инструкция по загрузке Excel-файла;
- `/export` — выгрузить актуальную таблицу;
- `/list` — показать список дней рождения текстом;
- `/help` — показать справку.

## Формат Excel-файла

Файл должен быть `.xlsx` и содержать только два столбца:

| ФИО | Дата |
| --- | --- |
| Иванов Иван | 25.10 |
| Петров Петр | 03.01 |

Заголовки должны быть в первой строке. При загрузке бот проверяет формат и заменяет текущую таблицу только если файл корректен.
